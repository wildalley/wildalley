## 关于我

我是 **wildalley**。日常使用 Arch Linux，喜欢折腾 Wayland 桌面，也喜欢把使用中遇到的真实问题做成可运行、可复用的开源工具。

最近在打磨 Framely「取景」截图工具和「渡 Ferry」跨平台代理客户端，也持续维护服务器监控、Air780E 多卡短信中枢、路由固件核心与 AI 编码扩展。开发过程、部署经验和踩过的坑，会整理到[博客](https://blog.yehenest.com/)里。

## 最近在做

- **[Framely · 取景](https://github.com/wildalley/framely)** — 原生桌面截图工具，提供 Windows、Linux 和 macOS 版本，支持标注、钉图、录屏与离线 OCR；Windows / Linux 另支持长截图。`Go · MyGo`
- **[渡 Ferry](https://github.com/wildalley/ferry)** — 原 sing-box Client，支持 Android、Linux 和 Windows，提供订阅导入、实时切换节点、路由规则、策略组及系统代理 / TUN 模式。`Dart · Flutter`
- **[Cyber Probe](https://github.com/wildalley/probe)** — 服务器监控系统，Agent 主动上报资源与网络探测结果，提供实时看板、历史记录、流量配额、资产管理和多渠道告警。`Go · React`
- **[Air780E Hub](https://github.com/wildalley/air780e-hub)** — 多卡短信中枢，支持短信收发、多渠道通知、定时保号与设备监控；本地 Agent 支持断网缓冲，通过 Web 统一管理。`Python · React`
